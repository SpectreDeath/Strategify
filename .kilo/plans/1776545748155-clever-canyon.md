# Economic Analyst Module Implementation Plan for Strategify

## Goal
Add specialized economic analysis capabilities to Strategify based on the Economist occupation (SOC 19-3011), enabling economic forecasting, policy impact analysis, and cost-benefit evaluation for state actor decisions.

## Current State Analysis

### Already Implemented
- `strategify/reasoning/economics.py` - TradeNetwork with GDP, population, sanctions modeling
- `StateActorAgent.capabilities["economic"]` - Basic economic capability score
- `TradeNetwork.get_economic_features()` - Returns trade_balance, gdp, etc.
- `strategify/analysis/war_game.py` - Basic economic impact analysis for strategies
- `strategify/analysis/strategy_recommend.py` - Economic leverage recommendations

### Gaps Identified
1. No dedicated economic forecasting component for agents
2. No policy impact analysis (taxes, regulations, public services)
3. No econometric modeling or statistical analysis tools
4. No cost-benefit analysis for agent decisions
5. No economic intelligence game type in crisis_games

---

## Implementation Plan

### Phase 1: EconomicForecaster Component (High Priority)

**Objective**: Attach economic analysis capabilities to StateActorAgent

**Files to Create/Modify**:
- Create: `strategify/agents/economic_analyst.py`
- Modify: `strategify/agents/state_actor.py` (add EconomicForecaster)
- Modify: `strategify/agents/__init__.py` (export new classes)

**Components**:
1. `EconomicDataPoint` dataclass - time series data structure
2. `EconomicIndicator` enum - GDP growth, inflation, unemployment, trade balance
3. `EconomicForecast` dataclass - forecast results with confidence intervals
4. `PolicyImpact` dataclass - cost-benefit analysis results
5. `EconomicForecaster` class:
   - `forecast_indicator(indicator, horizon)` - Time-series forecasting
   - `analyze_policy_impact(policy_type)` - Assess policy effects
   - `calculate_cost_benefit(proposal)` - ROI analysis
   - `get_market_trends()` - Identify economic patterns
6. `EconomicAdvisor` class:
   - `recommend_trade_policy()` - Optimize trade relationships
   - `advise_tariff_decision()` - Tariff cost-benefit
   - `assess_sanction_effectiveness()` - Sanction impact analysis

---

### Phase 2: Econometric Modeling Extension (Medium Priority)

**Objective**: Add statistical analysis and forecasting capabilities

**Files to Create/Modify**:
- Create: `strategify/economics/econometrics.py` (new subpackage)

**Components**:
1. `RegressionModel` class - Linear/logistic regression for economic data
2. `TimeSeriesAnalyzer` class - ARIMA-style forecasting
3. `SupplyDemandEquilibrium` class - Market equilibrium analysis
4. `FiscalImpactCalculator` class - Government spending effects
5. `TradeElasticityEstimator` class - Import/export sensitivity analysis

---

### Phase 3: Economic Intelligence Game (Medium Priority)

**Objective**: Add economic game type to crisis_games for agent decision-making

**Files to Create/Modify**:
- Modify: `strategify/game_theory/crisis_games.py`

**Components**:
1. `economic_intel_game()` - New game factory function
2. Actions: ["AnalyzeMarkets", "ImposeTariffs", "NegotiateTrade", "Sanction"]
3. Integration with `StateActorAgent.active_games` when `capabilities["economic"] > 0.6`

---

### Phase 4: Economic Advisor Integration (Lower Priority)

**Objective**: Connect economic analysis to agent decision-making

**Files to Modify**:
- `strategify/agents/state_actor.py`
- `strategify/analysis/strategy_recommend.py`

**Components**:
1. Agent decision hook for economic advice
2. Strategy recommendation integration with economic forecasts
3. Economic early warning system for crises
